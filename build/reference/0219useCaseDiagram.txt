Use Case Diagrams
Comments and Requirements
noreferences
@@tooltip The GvUseCaseDiagram generator draws a UML use case diagram from the useCase requirements in a model.

@@description
<p>A UML use case diagram can be drawn from the <code>useCase</code> requirements of a model (see <a href="Requirements.html">Requirements</a>). No extra syntax is needed: the diagram is built from what the requirements already say.</p>

<ul>
  <li>Each <code>useCase</code> requirement is drawn as an ellipse, showing its identifier and its <code>what</code> text.</li>
  <li>The <code>who</code> of a use case is drawn as an actor, associated with the use case. An actor named by several use cases is drawn once.</li>
  <li><code>include</code> is drawn as a dashed arrow labelled &laquo;include&raquo; to each included use case.</li>
  <li><code>isA</code> is drawn as a generalization arrow to each parent use case.</li>
</ul>

<p>The steps and conditions of a use case are not part of a use case diagram. They are shown in the requirements document generated by <code>PlainRequirementsDoc</code>.</p>

<p>To draw the diagram, add the following to an Umple file:</p>

<pre>
generate GvUseCaseDiagram;
</pre>

<p>Or use the command line:</p>

<pre>
umple -g GvUseCaseDiagram your_model.ump
</pre>

<p>This produces a Graphviz file ending in <code>ucd.gv</code>, which <code>dot</code> turns into an image.</p>

<p>In UmpleOnline, choose Use Case Diagram in the Live View menu, or GraphViz Use Case under Diagram Type in the options panel. It is also in the Generate menu as Use Case Diagram (GraphViz SVG).</p>
