E9215 Python Reserved Name
Errors and Warnings 1000+

@@description

<h2>A name that Python reserves or that generated code uses</h2>

<p>This error is reported for a class or interface named like a Python built-in that the generated code calls (for example <code>len</code>, <code>id</code>, <code>set</code> or <code>tuple</code>), which the class would hide in its module and in every method that imports it. It is also reported for a name that becomes a Python keyword in the generated code, which Python cannot define: a class, interface, method, event, state, constant, enumeration or enumeration value named, for example, <code>lambda</code>, <code>async</code>, <code>break</code> or <code>None</code> (enumeration values are written with a capital first letter, so <code>none</code> becomes <code>None</code>). Finally, it is reported for a parameter named <code>__class__</code>, the name generated methods use for their own class. The class is not generated.</p>

<p>Rename the element.</p>
