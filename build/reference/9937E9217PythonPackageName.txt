<h2>A namespace is not a valid Python package name</h2>

<p>A class in a namespace is generated as a module of the package named by the namespace, so each part of the namespace must be made of ASCII letters, digits and underscores, must not start with a digit, and must not be a Python keyword. Namespaces such as <code>releases.2024</code> or those taken from URLs cannot be imported, so their classes are reported and not generated. Use a namespace made of such names. A namespace whose first part is a standard Python module is reported with <a href="E9213PythonModuleNameClash.html">E9213</a>.</p>
