<h2>A namespace is not a valid Python package name</h2>

<p>A class in a namespace is generated as a module of the package named by the namespace, so each part of the namespace must be a Python identifier: letters, digits and underscores, not starting with a digit, and not a Python keyword. Namespaces such as <code>releases.2024</code> or those taken from URLs cannot be imported, so their classes are reported and not generated. Use a namespace made of identifiers.</p>
