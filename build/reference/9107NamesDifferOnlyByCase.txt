W107 Names Differ Only By Case
Errors and Warnings 100-999
noreferences

@@description

<h2>
Umple semantic warning reported when two or more classes or interfaces, attributes of a class, or mixsets have names that differ only in case
</h2>

<p>Names such as <i>Ping</i> and <i>PinG</i>, or <i>apple</i> and <i>apPle</i>, are distinct identifiers
to Umple and to languages such as Java, but they are easily confused by people and can lead to defects
(see <a href="https://cwe.mitre.org/data/definitions/178.html">CWE-178</a>).
They also cause concrete problems in generated code. Each class and interface becomes a file named after it,
so when two of them are generated into the same directory on a case-insensitive file system, such as the defaults
on Windows and macOS, one file overwrites the other.
Attribute names are capitalized to form method names, so <i>apple</i> and <i>apPle</i> produce
<i>setApple</i> and <i>setApPle</i>, which PHP treats as the same method.
Mixsets named, for example, <i>M1</i> and <i>m1</i> are separate mixsets, and a use statement that names one of them does not include the other.
</p>

<p>Class and interface names are compared together. The attributes of a class are compared with each other,
including those it inherits from its superclasses and those it gets from traits; the same letters in unrelated classes are fine.
Mixsets are compared wherever they are declared, including inside method bodies.
The message lists all the names that clash and points at the first of them that duplicates an earlier one.
A clash with an inherited attribute is reported once, at the subclass attribute that introduces it.
When the names differ only in the case of their first letter, such as <i>attr</i> and <i>Attr</i>, the generated methods are identical
and error <a href="E048DuplicateGeneratedMethod.html">E048</a> is reported as well when Java or PHP code is generated.
To avoid the message, rename the elements so their names differ by more than their case.
</p>

<p>The first example below is not compiled when the manual is built, since its generated code
shows exactly these problems: on some file systems and in PHP it does not compile.
</p>
