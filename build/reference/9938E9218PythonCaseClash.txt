@@description

<h2>Two namespaces or classes differ only in case</h2>

<p>Each namespace becomes a Python package folder and each class a module file. Python matches the case of module names even where file names ignore case, as on Windows and macOS. There, namespaces such as <code>Shop</code> and <code>shop</code> would share one folder, and classes such as <code>Item</code> and <code>item</code> in one namespace would share one file, so one of them could not be imported. The Python generator reports the second class or interface and does not generate it.</p>

<p>Spell the namespace the same way everywhere, or give one of the classes another name.</p>
