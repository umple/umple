<p>
PythonNext is Umple's newer Python generator, chosen with <code>generate PythonNext;</code> in a model, <code>-g PythonNext</code> on the command line or Python Code (PythonNext) in UmpleOnline. It generates Python 3 classes directly from the model, and lets you embed Python methods in Umple. It generates the API of the Java generator (the same method names and parameters, except the accessors of a sorted association's comparator), so your Umple code can create classes with attributes, associations and state machines in generated Python.</p>

&nbsp;<br/>

<p><b>Embedding Python methods:</b> To insert Python methods in Umple, you specify the method signature followed by the keyword Python followed by an open curly bracket, then any number of lines of Python code, and finally a closing curly bracket. The code is used exactly as written, with its indentation. Umple finds the closing curly bracket with Java's rules for comments: a curly bracket in a <code>#</code> comment counts, and the rest of a line after Python's <code>//</code> operator is skipped as a comment, so keep curly brackets in comments balanced and put the closing curly bracket on a line of its own after such a line. A method can have a Java body and a Python body side by side; each generator uses its own. A method body without a language tag is taken to be Python, and a method that has only bodies for other languages is left out of the Python (with warning <a href="W9212PythonNoPythonCode.html">W9212</a>). The same holds for actions, activities and code injections written only for other languages. A derived attribute written only for other languages would have no value, so it is reported with error <a href="E9211PythonUntranslatableCode.html">E9211</a>.</p>

<p>To create a <b>main Python function</b> in a class use the same method signature as for Java, except tag the code as Python. So a main function first line would look like the following <code>public static void main(String [ ] args) Python {  </code>. This would be followed by Python code, and ends with a closing curly bracket <code>}</code>. Running the generated module calls main with the full <code>sys.argv</code>.</p>

<p>Code that refers to another class of the model imports it inside the method, as generated code does, for example <code>from shop.Item import Item</code>, where <code>shop</code> is the class's namespace.</p>

&nbsp;<br/>

<p><b>Untagged code in actions, injections and defaults:</b> Actions of state machines, entry, exit and do activities, code injections, derived attributes and default values written without a language tag are written in Java syntax. For Python, Umple translates such code when it uses a small subset of Java (literals, local variables, assignments, conditions and loops, calls to the model's own methods, <code>new</code> for model classes, <code>System.out.println</code> and <code>throw new RuntimeException</code>). Other code is reported with error <a href="E9211PythonUntranslatableCode.html">E9211</a>, which shows how a Python version of that kind of code is written. In text, booleans, the <code>null</code> literal and a missing model object read <code>true</code>, <code>false</code> and <code>null</code>, as in Java. Python-tagged versions of such code are used as written.</p>

&nbsp;<br/>

<p><b>The generated Python:</b></p>
<ul>
    <li>Each class is a module <code>ClassName.py</code> in the package given by its namespace.</li>
    <li>Setters and add/remove methods return <code>True</code>, or <code>False</code> when the change is refused (for example by a constraint, a multiplicity bound or a key that can no longer change).</li>
    <li>Getters of association ends with many objects return tuples; getters of list attributes return copies.</li>
    <li>Links between objects are compared by identity. Classes with a <a href="KeysforEqualityandHashing.html">key</a> also get <code>__eq__</code> and <code>__hash__</code> based on the key.</li>
    <li><code>str()</code> of an object has the layout of Java's toString, with Python's spelling of values (<code>True</code>, <code>None</code>) except that a missing date or linked object prints <code>null</code> as in Java, or is the result of a toString method written in the model.</li>
    <li>Parameters named like Python keywords are renamed: <code>in</code> becomes <code>input</code>, and other keywords get a trailing underscore.</li>
    <li>Overloaded methods become one method that calls the most specific overload matching the arguments, judged by their types when the program runs (Java judges by the declared types of the expressions passed). A method written in the model with the same parameter types as a method Python generates (for example a Python <code>delete()</code>) replaces that method, as a later definition does in Python; other overloads of the name stay. <code>int</code> and <code>Integer</code> count as one type. Overloads are dispatched per class: a subclass that declares a method of an inherited name replaces the whole inherited group, and reaches the parent's methods, generated ones included, through <code>super()</code> (calling <code>self</code> would call its own method again). Generated code still calls the method by its name, so the parent's constructor and the other class of an association reach the subclass's method too: avoid giving a subclass method the name of a method Python generates for its parent (such as <code>addItem</code> of an association or <code>resetLevel</code> of a defaulted attribute).</li>
    <li>Guards, preconditions and invariants can use Java's <code>equals</code> and <code>contains</code>, which become <code>==</code> and <code>in</code>.</li>
    <li>Translated code computes with Python's numbers: integers do not overflow at 32 or 64 bits, <code>Float</code> has double precision, and a floating division by zero raises <code>ZeroDivisionError</code> where Java gives NaN or infinity.</li>
    <li>Timers and do activities of state machines use Python threads. Leaving a state or deleting the object cancels its timers and asks its do activity to stop; an activity that runs for long checks <code>thread.cancelled.is_set()</code>, where <code>thread</code> is the worker it runs in, and returns when it is set. An event on a deleted object does nothing and returns <code>False</code>.</li>
</ul>

&nbsp;<br/>

<p><b>Python in UmpleOnline:</b> Python code can be executed in UmpleOnline. To get methods to execute as Python methods, you need to tag them with the keyword Python before the opening curly bracket, as described above. You need at least one main method. When your code is ready, select Python Code (PythonNext) from the Generate menu, and then click Execute It. If you make syntax errors or have runtime errors in your embedded Python, UmpleOnline shows the error: for code written without a language tag it names the line of your model, and for Python-tagged code and the bodies of state-dependent methods the line of the generated Python.</p>

&nbsp;<br/>

<p><b>Command line use:</b> Generating Python on the command line needs only Umple (<code>java -jar umple.jar -g PythonNext model.ump</code>). Checking the generated Python for syntax errors (the <code>-c</code> option) needs Python 3; Umple looks for <code>python3</code>, then <code>python</code>, or uses the interpreter named by the environment variable <code>UMPLE_PYTHON</code>. The check never runs the generated code.</p>

<br><br>

<p>
Currently unsupported features, reported with error <a href="E9210PythonUnsupported.html">E9210</a> (the class concerned is then not generated):
<ul>
    <li>Tracing.</li>
    <li>Distributed classes.</li>
    <li>Queued and pooled state machines, and queued methods.</li>
    <li>Synchronized methods.</li>
    <li>Custom constructors and <code>emit</code> template methods.</li>
    <li>Around injections and injections at code labels.</li>
    <li>Association specialization.</li>
    <li>An inner class whose superclass is an inner class declared elsewhere in the same outer class, or is that outer class (a superclass declared beside it works).</li>
    <li>JSON generation (the genJson suboption).</li>
    <li>A guard testing a state with <code>is in state</code>.</li>
    <li>A guard, precondition or invariant that calls a Java library method other than <code>equals</code> and <code>contains</code>, or that names something the model does not define or another class.</li>
    <li>A method named like another that is static where the other is not, including a method Python generates for the class.</li>
</ul>
</p>

<p>
If any of the features that are supported appear to function incorrectly, please submit <a target="newissue" href="https://github.com/umple/umple/issues/new">a new issue here</a>.
</p>
