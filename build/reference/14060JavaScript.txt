@@description
<p>
The JavaScript generator generates basic JavaScript classes from Umple class models, and lets you embed JavaScript methods in Umple. It is chosen with <code>generate JavaScript;</code> in a model, <code>-g JavaScript</code> on the command line, or JavaScript Code in UmpleOnline. One module is generated for each class. JavaScript is generated by the Umple compiler itself, so nothing else needs to be installed.</p>

<p>The generated code uses CommonJS modules: each class is exported with <code>module.exports</code>, a subclass obtains its superclass with <code>require</code>, and so does a class whose methods use another generated class. The generated files run under Node.js without any other library.</p>

&nbsp;<br/>

<p><b>Supported features:</b></p>
<ul>
    <li>Classes, including abstract classes. An abstract class throws a <code>TypeError</code> if a <code>new</code> expression names it, as only a subclass is meant to be created.</li>
    <li>Attributes of type String, Integer, Double and Boolean, including <code>lazy</code>, <code>defaulted</code> and <code>immutable</code> attributes, with the generated constructor, getters and setters. A Boolean attribute also gets its <code>is</code> method.</li>
    <li>Inheritance with <code>isA</code>, over any number of levels, within one namespace.</li>
    <li>Associations whose ends are optional (<code>0..1</code> or <code>*</code>), including directed associations, compositions and reflexive associations, with the generated get, set, add, remove, index and delete methods.</li>
    <li>Methods written in the model with a JavaScript body, and abstract methods.</li>
    <li>Comments on classes, attributes, associations and methods, which become JSDoc comments.</li>
</ul>

&nbsp;<br/>

<p><b>Embedding JavaScript methods:</b> To insert a JavaScript method in Umple, write the method signature followed by the keyword JavaScript, an open curly bracket, any number of lines of JavaScript, and a closing curly bracket, as in <code>String greet() JavaScript { return "Hello, " + this.getName(); }</code>. The body is used as written, indented to fit the generated method. A method can have a Java body and a JavaScript body side by side; each generator uses its own. A body with no language tag is used by every generator, so it must be valid JavaScript when JavaScript is generated. A method with bodies only for other languages is left out of the generated class with warning <a href="W9222JavaScriptNoJavaScriptCode.html">W9222</a>.</p>

<p>Inside a body, use <code>this</code> to reach the generated getters, setters and association methods of the object, as in <code>this.getName()</code> or <code>this.addLine(aLine)</code>. The return type of the method is only documentation in JavaScript, and <code>static</code> generates a static method. Another generated class of the same folder can be used by name, as in <code>new Line(aName, aQuantity)</code>: the generated module requires it after exporting its own class, so two classes that use each other both load. An abstract method is generated with a body that throws a <code>TypeError</code>, so a call that is not answered by a subclass is reported rather than silently doing nothing.</p>

<p>Umple finds the closing curly bracket with Java's comment rules, so keep curly brackets inside <code>//</code> and <code>/* */</code> comments balanced, and avoid them in regular expression and template literals.</p>

<p><b>Method modifiers:</b> <code>static</code> generates a static method. <code>public</code>, <code>protected</code> and <code>private</code> all generate an ordinary method, because JavaScript enforces no access control on a method declared this way, as Python does not either. <code>synchronized</code> also generates an ordinary method: a synchronous JavaScript body runs to its end before anything else does, so there is nothing for it to lock. A <code>queued</code> method needs a thread of its own and is reported with error <a href="E9220JavaScriptUnsupported.html">E9220</a>.</p>

&nbsp;<br/>

<p><b>The generated JavaScript:</b></p>
<ul>
    <li>Each class is a module <code>ClassName.js</code>, in the folder given by its namespace, exporting the class.</li>
    <li>Attribute values and links are held in properties named after the attribute or role with a leading underscore, such as <code>this._name</code>. They are not part of the API: use the generated methods.</li>
    <li>Attribute setters and the methods that set, add or remove links return <code>true</code>, or <code>false</code> when the change is refused.</li>
    <li>An association end that holds one object starts as <code>null</code>, as it reads after being unset, rather than <code>undefined</code>. An end that holds many objects starts as an empty array, and its getter returns a copy of that array.</li>
    <li>The <code>delete</code> method unlinks the object from every association and, for a composition, deletes the parts, as in the generated Java.</li>
    <li>The initial value of an attribute is copied to the generated code as it is written, so it must be a literal, such as <code>3</code>, <code>-1.5</code>, <code>true</code>, <code>"text"</code> or <code>null</code> for a String. Expressions are not translated from Java, so even a constant expression such as <code>2*3</code> is unsupported: write its value instead. Numbers must also be valid in Java: an Integer value must fit in an int, and a number cannot have a leading zero (as in 010) or a suffix (as in 10L).</li>
</ul>

&nbsp;<br/>

<p><b>Command line use:</b> <code>java -jar umple.jar -g JavaScript model.ump</code> writes the modules beside the model. Run them with Node.js, for example <code>node -e "const Team = require('./Team.js'); console.log(new Team('Reds').getName());"</code>.</p>

<p><b>JavaScript in UmpleOnline:</b> Select JavaScript Code from the Generate menu. The generated modules are shown one tab per class and can be downloaded as a zip file.</p>

<br><br>

<p>
Currently unsupported features, reported with error <a href="E9220JavaScriptUnsupported.html">E9220</a> (the class concerned is then not generated, while the other classes still are):
<ul>
    <li>State machines.</li>
    <li>Interfaces, singletons, keys, constraints, constants, enumerations and tracing.</li>
    <li>Code injection (before, after and around).</li>
    <li>Constructors and queued methods written in the model, and two methods of one name (JavaScript has no overloading).</li>
    <li>Associations with a mandatory end (such as <code>1</code> or <code>1..*</code>) or a bounded multiplicity (such as <code>0..3</code>), sorted associations, specialized associations, and immutable associations with a many end.</li>
    <li>Two methods a class would generate under one name, since JavaScript has no overloading: an association role name whose singular is the role name itself, such as <code>series</code>, gives the method taking an index and the method returning the list one name; so does an attribute named like the singular of a many role, as <code>item</code> is of <code>items</code>. A method written in the model that repeats a generated name, such as a second <code>delete()</code>, is reported for the same reason.</li>
    <li>Inner classes, and the classes that contain them.</li>
    <li>A superclass in another namespace, an external superclass (an external class is never generated, so the module could not be loaded), and a subclass of a class that is not generated.</li>
    <li>Attributes of other types, such as Date, Time or lists, <code>fixml</code> attributes, <code>unique</code> and <code>autounique</code> attributes, and derived attributes.</li>
    <li>Initial values that are not literals, such as <code>7/2</code>, <code>start + 1</code> or a method call.</li>
    <li>Code in a class that Umple could not interpret (extra code).</li>
    <li>Distributed classes.</li>
    <li>The generated toString method.</li>
</ul>
A class or parameter whose name JavaScript reserves, or that is one of Node's own module variables, is reported with error <a href="E9221JavaScriptReservedName.html">E9221</a>.
</p>

<p>
If any of the features that are supported appear to function incorrectly, please submit <a target="newissue" href="https://github.com/umple/umple/issues/new">a new issue here</a>.
</p>
