@@tooltip Use statements to incorporate the contents of another Umple file or activate a mixset

@@description
<p>Use statements allow you to decompose your system by embedding or referencing files containing other model elements (such as classes) into your current model, or to include optional code blocks defined in <a href="BasicMixsets.html">mixsets</a>.</p>

<p>A model file or mixset is included only once; subsequent "use" commands 
for the same file will be ignored. Preceding a mixset name with '!' indicates to not use the mixset, and cancels out any previous use statement that requested to use the mixset.</p>

<p>A common technique is to create a 'master' Umple file that does nothing but have a list
of use statements.</p>

<p>Parts of an individual class can be specified in separate files, and brought together using several use statements. For example the associations or attributes could be in one (or several) files, and the methods could be in one (or more) additional files.</p>

<p>Another way to decompose a system is to have a 'core' set of files that can be included in several different systems using &#39;use&#39; statements.</p>

<p>Use statements function similarly to 'include' statements in other languages.</p>

<p>A file referred to by a use statement must be in the same directory as the file that has the use statement, or in a parent directory, or in a subdirectory named lib.</p>

<p>Umple also ships built-in library files for common modeling patterns. Load one with the <code>lib:</code> prefix. The file is read from inside the Umple compiler, so it does not need to be in your project directory:</p>

<pre>
use lib:AbstractionOccurrence.ump;
</pre>

<p>The built-in pattern libraries are:</p>
<ul>
<li><a href="AbstractionOccurrence.html">Abstraction Occurrence</a> (<code>use lib:AbstractionOccurrence.ump;</code>)</li>
<li><a href="PlayerRole.html">Player Role</a> (<code>use lib:PlayerRole.ump;</code>)</li>
<li><a href="TransportationPatternA.html">Transportation Pattern A</a> (<code>use lib:TransportationPatternA.ump;</code>)</li>
</ul>

<p>Each of those pages shows the pattern definition and an example of applying it in a model.</p>

<p>A use statement can also load a <code>.ump</code> file from the web. The argument must be an <code>https</code> URL that ends in <code>.ump</code>. A raw file on GitHub is a typical source:</p>

<pre>
use https://raw.githubusercontent.com/umple/umple/master/umpleonline/umplibrary/reusable/AbstractionOccurrence.ump;
</pre>
