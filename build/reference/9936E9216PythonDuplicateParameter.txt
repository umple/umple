<h2>Two parameters get the same Python name</h2>

<p>PythonNext renames a parameter named like a Python keyword: <code>in</code> becomes <code>input</code>, and other keywords get a trailing underscore (<code>lambda</code> becomes <code>lambda_</code>). When two parameters of a method then have the same name, PythonNext reports this error at the method (for an event, at its class) and does not write a Python file for the class. Rename one of the parameters.</p>
